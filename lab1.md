## 📚 Конспект по Проекту "Анимированные Конусы" (Vulkan/veekay)

Данный документ описывает структуру и логику работы программы компьютерной графики, реализующей рендеринг и анимацию множества конусов с использованием API Vulkan и фреймворка `veekay`.

---

## I. Структуры Данных (Моделирование и Сцена)

| **`Mesh`** | Описание формы объекта. Хранит данные для GPU. | `vertex_buffer`: Указатель на буфер вершин. `index_buffer`: Указатель на буфер индексов (позволяет переиспользовать вершины). `indices`: Общее количество индексов (сколько треугольников рисовать). |

### 2. Трансформации и Камера

| Структура | Назначение | Метод |
| :--- | :--- | :--- |
| **`Transform`** | Описывает положение, ориентацию и размер объекта в мировом пространстве. | `matrix()`: **Модельная Матрица (Model Matrix)**. Комбинирует Scale, Rotation, Translation (S-R-T) в порядке $T \times R \times S$. |
| **`Camera`** | Наблюдатель сцены. | `view()`: **Матрица Вида (View Matrix)**. Переводит мир в пространство камеры. `view_projection()`: **VP-Матрица**. Комбинация View и Projection. |

| Структура | Назначение | Поля |
| :--- | :--- | :--- |

## II. Uniform Buffers (Данные для GPU)

Uniform Buffers (UB) используются для передачи глобальных данных и данных объектов из CPU на GPU.

| Структура | Тип Буфера | Содержимое | Обновление |
| :--- | :--- | :--- | :--- |
| **`SceneUniforms`** | Статический UB (Binding 0) | `view_projection` (VP-Матрица). | Раз за кадр в функции `update`. |
| **`ModelUniforms`** | Динамический UB (Binding 1) | `model` (Модельная Матрица). `albedo_color` (Цвет объекта). | Для каждой модели раз за кадр в функции `update`. |

> **Ключевой момент: Динамический Uniform Buffer:** Буфер `model_uniforms_buffer` хранит данные для всех 1024 возможных моделей. Благодаря **выравниванию** (`structureAlignment`) и использованию динамических смещений, GPU может выбрать нужный блок данных для конкретной модели в цикле отрисовки.

## III. Создание Геометрии и Инициализация Сцены

### 1. Задание Геометрии (`createConeMesh`)

*   **Назначение:** Создание геометрии конуса (вершины и индексы).
*   **Механизм:** Вершины основания и вершины боковой поверхности рассчитываются в цикле с использованием тригонометрии (косинус и синус) для равномерного распределения по окружности.
*   **Результат:** Инициализируется один набор `cone_mesh` (один `vertex_buffer` и один `index_buffer`), который используется **всеми** моделями (эффективное использование памяти).

### 2. Задание Конусов и Цвета (Блок `// NOTE: Add animated cones...` в `initialize`)

*   **Механизм:** Вектор `models` заполняется пятью экземплярами.
*   **Траектория / Анимация:** Изначальная позиция (`position`), масштабирование (`scale`), ось вращения (`rotation_axis`) и скорость (`rotation_speed`) задаются один раз (в массиве `cones`).
*   **Цвет:** Поле `albedo_color` для всех моделей устанавливается в `cone_color` (`{0.95f, 0.55f, 0.2f}`).

## IV. Динамика и Анимация (Функция `update`)

Функция `update` выполняется на CPU перед рендерингом.

### 1. Расчет Движения (Траектория)

```c++
// Расчет дельта-времени
float delta_time = static_cast<float>(time - previous_time); 
// ...
const float scaled_delta = delta_time * rotation_speed_multiplier;

for (Model& model : models) {
    const float angle_delta = model.rotation_speed * scaled_delta;
    model.transform.rotation += model.rotation_axis * angle_delta;
}
```

*   **Задача:** Обеспечить *кадронезависимую* анимацию.
*   **Логика:** Угол вращения (`model.transform.rotation`) увеличивается пропорционально:
    1.  Заданной скорости объекта (`rotation_speed`).
    2.  Прошедшему времени (`delta_time`).
    3.  Общему множителю скорости (`rotation_speed_multiplier`, управляемому через ImGui).

### 2. Обновление Данных на GPU

1.  **Scene UB:** Рассчитывается новая VP-матрица камеры. Данные копируются в `scene_uniforms_buffer->mapped_region`.
2.  **Model UB:**
    *   Для каждой модели рассчитывается новая `ModelUniforms` (включая обновленную Model Matrix).
    *   Данные копируются в `model_uniforms_buffer->mapped_region`, используя **сдвиг, кратный выравниванию**, чтобы избежать конфликтов на GPU: `pointer = base_address + i * alignment`.

## V. Графический Конвейер и Рендеринг (Vulkan)

### 1. Инициализация Конвейера (`initialize`)

*   **Шейдеры:** Загружаются `shader.vert.spv` (Vertex Shader) и `shader.frag.spv` (Fragment Shader).
    *   **Цвет:** Цвет задается через Uniform Buffer (`ModelUniforms.albedo_color`) и читается во фрагментном шейдере для раскрашивания пикселей.
*   **Дескрипторы:** Настраивается `descriptor_set_layout` для привязки Scene (Binding 0, UB) и Model (Binding 1, Dynamic UB) данных.
*   **Состояние Растеризации:** Включен Cull Mode (отсечение задних граней) и Depth Testing (тестирование глубины, чтобы правильно отображать перекрытие объектов).

### 2. Цикл Отрисовки (`render`)

Рендеринг происходит в цикле командного буфера.

1.  **Начало Рендер-Прохода:** Устанавливается `veekay::app.vk_render_pass`, и происходит очистка кадра (черный фон) и буфера глубины.
2.  **Привязка Конвейера и Геометрии:** Привязывается `pipeline` и общие буферы вершин/индексов (`cone_mesh`).
3.  **Помодельный Цикл Отрисовки:**
    ```c++
    uint32_t offset = i * model_uniorms_alignment;
    vkCmdBindDescriptorSets(cmd, ..., 1, &descriptor_set, 1, &offset);
    vkCmdDrawIndexed(cmd, mesh.indices, 1, 0, 0, 0);
    ```
    *   **Принцип:** Для каждого конуса команды `vkCmdBindDescriptorSets` используют вычисленный `offset`. Этот динамический сдвиг указывает GPU, откуда именно в большом `model_uniforms_buffer` нужно взять Model Matrix и цвет для текущего объекта.
    *   **Результат:** Вызывается `vkCmdDrawIndexed`, который использует привязанную геометрию и индивидуальные матрицы для проецирования конуса на экран.
